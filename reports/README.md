# reports/ — Reportes de actividad

Un archivo por sesión/tarea: `AAAA-MM-DD_<tema>.md`.

Cada reporte documenta:
- **(a)** lo solicitado (requerimientos)
- **(b)** lo ejecutado (acciones, archivos tocados, comandos clave)
- **(c)** resultado vs. definición de hecho
- **(d)** pendientes / siguiente paso

Protocolo completo en `../CONTRIBUTING.md`.

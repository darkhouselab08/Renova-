# Equipo de agentes de Renova

El **Gerente** (agente líder) vive en `../../CLAUDE.md` y se auto-carga al entrar al repo.
Aquí están sus **5 jefes de departamento** (sub-agentes que el Gerente invoca con la herramienta Task):

- `frontend.md` — Frontend / Producto (UI)
- `backend-datos.md` — Backend / Datos
- `diseno.md` — Diseño / Marca
- `seguridad-qa.md` — Seguridad / Calidad
- `devops.md` — DevOps / Deploy

Cada uno declara su rol, las carpetas que cuida y qué NO hace. El organigrama para personas está en
`../../docs/departamentos/`.
